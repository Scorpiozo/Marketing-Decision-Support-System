Decision policy

The model only estimates a probability. This page is where that estimate becomes an action, using explicit, editable business assumptions. Change them and every page (lead cards, rankings, overview) updates.

Assumptions

Defaults (€5 per contact, €50 per subscription) are illustrative assumptions, not real bank economics. A real deployment would set them with the bank's finance and compliance teams.

The rules (first match wins)

  1. Human review if re-trained versions of the model disagree about which side of the follow-up line the lead is on.
  2. Prioritise if the estimate ≥ priority threshold.
  3. Follow up, change approach if above the follow-up line but already heavily contacted.
  4. Follow up if estimate ≥ follow-up line (break-even = cost ÷ value).
  5. Stop repeated follow-up if below the line and already heavily contacted.
  6. Deprioritise otherwise.

Break-even follows expected value (Elkan, 2001): another call is worth it when P(subscribe) × value > cost. This works only because the model's probabilities are calibrated. The “heavily contacted” rule is a proxy for contact fatigue: the data shows conversion falling with each extra contact, but has no direct fatigue label.
