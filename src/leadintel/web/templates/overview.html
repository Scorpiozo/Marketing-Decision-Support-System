Research prototype · decision support for relationship managers

Which leads deserve another call, and why?

A bank's sales team contacts the same leads again and again. This system reads each lead's interaction pattern (previous-campaign outcome, contacts so far, how recently they were contacted) together with their profile, estimates how likely they are to subscribe, and turns that estimate into a recommended next action with the evidence behind it. A person makes the final decision.

What the research found

    {% if full and ctx %}
  • Interaction history adds real signal. Adding previous-outcome, recency and contact counts to profile + context raised PR-AUC from {{ "%.3f" | format(ctx.test.pr_auc) }} to {{ "%.3f" | format(full.test.pr_auc) }}, and it is the most robust feature group when testing on a later period.
    • {% endif %} {% if leak and full %}
  • The original 0.92 AUC was inflated by leakage. It used call duration, which is only known after the call that decides the outcome. In our tests the same model scores {{ "%.2f" | format(leak.test.roc_auc) }} with it and {{ "%.2f" | format(full.test.roc_auc) }} without it. This system does not use it.
    • {% endif %}
  • Probabilities are honest. Mean estimate {{ pct(tm.mean_predicted, 1) }} vs. actual {{ pct(tm.base_rate, 1) }}. The original class-balanced models over-stated probabilities 2–3×.
  • The 1D CNN was not justified. Shuffling its input column order made no difference, so it found no “local” structure. See Model & XAI.
